# Fashion Data Pipeline

멀티 패션 플랫폼의 상품 데이터를 수집하고,
사이즈 실측·이미지·트렌드 정보를 정규화하여
개인화 패션 추천에 활용할 수 있도록 만든 데이터 파이프라인 프로젝트입니다.

## 목표

이 프로젝트는 단순 상품 수집이 아니라 다음 세 가지 추천을 지원하는 것을 목표로 합니다.

- 트렌디한 상품 추천
- 사용자에게 잘 어울리는 스타일 추천
- 실제 신체 치수에 맞는 사이즈 추천

## 주요 기능

- MUSINSA 상품/실측 데이터 수집
- 29CM 상품 수집 및 이미지 OCR 처리
- 상품/사이즈/이미지 데이터 MySQL 적재
- 데이터 품질 검증
- 리뷰수, 평점, 좋아요, 판매량, 인기순위 기반 트렌드 시계열 저장
- 향후 패션 온톨로지 기반 스타일 추천 연계

## 프로젝트 구조

fashion-portfolio/
├── collectors/     # 플랫폼별 상품 수집
├── loaders/        # MySQL 적재
├── enrichers/      # 이미지, OCR, 추가 정보 보강
├── quality/        # 데이터 품질 검증
├── ocr_console/    # OCR 작업 관리
├── pipelines/      # 반복 실행 스크립트
├── core/           # 공통 설정 및 공용 코드
├── sql/            # DB 스키마
└── README.md
